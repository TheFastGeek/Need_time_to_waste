# Need_time_to_waste
## Overview
Source code of a UNO-like game made in 48 hours for the GMTK Game Jam 2026, but where your goal is to do everything not to run out of time! Available right now on PC.

## How to play
The game's base is mostly like UNO: you have to put cards on top of the others by making their colors or symbols match. You have to do it while keeping track of the time you have left to play.\
Each card has a special effect. Some give you extra seconds, while others make your opponents waste their time.\
Be the last player standing to win !

## Where to download
The game is available on itch.io. Follow [this link](https://fastgeek.itch.io/need-time-to-waste) to download it.
